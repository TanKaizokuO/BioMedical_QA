   - **Artifacts**: Real measured wall-clock duration (`wall_s`) recorded in verifier `CostRecord`s PLUS an operator-supplied GPU hourly rate (`--verifier-gpu-hourly-rate <float>`).
   - **Constraint**: Supplying `--verifier-gpu-hourly-rate` without measured `wall_s` is refused by `scripts/g3_report.py` and leaves the cost clause unpriced (`verifier_cost_unpriced`).

## 4. Reproduction Commands

All commands are copy-pasteable and executed from the repository root:

### Step 1: Populate Verifier Scores
Populates `Claim.verifier_scores` on QueryRecords reading from the read-only MiniCheck cache:
```bash
uv run python scripts/populate_verifier_scores.py \
  --records docs/harvest/generate_fp05_n100_guided_v4.records.jsonl \
  --cache docs/harvest/minicheck_cache.json \
  --out docs/harvest/generate_fp05_n100_guided_v4.verifier_scored.records.jsonl
```

### Step 2: Estimate Opus-5 Judge Cost (Offline Non-Execution Estimate)
Generates the offline judge cost estimation artifact without network access or API calls:
```bash
uv run python scripts/estimate_judge_cost.py \
  --records docs/harvest/generate_fp05_n100_guided_v4.verifier_scored.records.jsonl \
  --out docs/harvest/runbooks/judge_cost_estimate.json
```

### Step 3: Run Gate G3 Verdict Driver
Executes Gate G3 report generation and outputs strict JSON verdict artifact:
```bash
uv run python scripts/g3_report.py \
  --records docs/harvest/generate_fp05_n100_guided_v4.verifier_scored.records.jsonl \
  [--annotations ann1.jsonl ann2.jsonl ann3.jsonl] \
  [--keyfile keyfile.jsonl] \
  [--primary-annotator annotator_1] \
  [--cost-ratio 10.0 | --costs costs.jsonl] \
  [--verifier-gpu-hourly-rate 0.85] \
  [--verifier lytang/MiniCheck-Flan-T5-Large] \
  --out docs/harvest/g3_verdict.json
```
